# room-vibe

## Description
Room-Vibe is a hostel booking and management system designed to simplify the process of managing hostel accommodations. It provides features for booking rooms, managing reservations, and handling various administrative tasks related to hostel management.

## How to Run the Slim App

1. **Clone the Project**
    ```sh
    git clone https://github.com/your-username/room-vibe.git
    cd room-vibe/slim-php
    ```

2. **Install Dependencies**
    ```sh
    composer install
    ```

3. **Run the Application**
    ```sh
    php -S localhost:8080 -t public
    ```

4. **Access the Application**
    Open your web browser and navigate to [http://localhost:8080](http://localhost:8080).

## Contribution Guidelines

1. **Clone the Project**
    ```sh
    git clone https://github.com/your-username/room-vibe.git
    cd room-vibe
    ```

2. **Pull from Main**
    ```sh
    git pull origin main
    ```

3. **Create Your Own Branch**
    ```sh
    git checkout -b your-branch-name
    ```

4. **Add Features and Work on It**
    Make your changes and add new features.

5. **Commit and Push to Your Branch**
    ```sh
    git add .
    git commit -m "Your commit message"
    git push origin your-branch-name
    ```

6. **Make a Pull Request**
    - If you are working on the Next.js framework, make a pull request to the `next-js-main` branch.
    - If you are working on the Slim framework, make a pull request to the `slim-php-main` branch.

7. **Final Pull Request**
    - After everything is worked on, pushed to your own branches, and the pull request is made to the framework-main origin branch without any conflicts, make a pull request from the framework-main branch to the main branch.
